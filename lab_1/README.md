# Модель файловой системы

Консольная (CLI) программная система, моделирующая работу с файлами, папками, дисками, пользователями и правами доступа. Проект имитирует поведение реальной файловой системы: создание и удаление файлов, копирование и перемещение, управление правами, архивирование и резервное копирование. Состояние сохраняется между запусками.

Лабораторная работа №1 по курсу «Проектирование программного обеспечения интеллектуальных систем» (часть 2). Вариант 58 — «Модель файловой системы».

## Предметная область

Система описывает организацию и управление файлами на компьютере. Основные сущности:

- **Диск** — хранилище с ограниченным объёмом, содержит корневую папку.
- **Папка** — контейнер для файлов и других папок.
- **Файл** — содержимое определённого формата.
- **Пользователь** — владелец элементов, состоит в группах.
- **Права доступа** — правила чтения, записи и выполнения для владельца, группы и остальных.
- **Формат файла** — тип содержимого (txt, pdf, jpg, zip, py, json, exe), определяющий категорию.

## Возможности

- Создание, чтение, запись и удаление файлов и папок
- Копирование и перемещение (переименование) файлов
- Навигация по дереву каталогов (`cd`, `ls`, `pwd`, `tree`)
- Управление правами доступа в стиле Unix (`chmod`, `chown`, `lsperm`)
- Архивирование файлов в ZIP и распаковка
- Резервное копирование диска и восстановление из копии
- Автоматическая сортировка файлов по категориям (`organize`)
- Сохранение и восстановление состояния между запусками

## Архитектура

В основе иерархии лежит абстрактный класс `FileSystemEntry`, от которого наследуются `File` и `Folder`. Это позволяет единообразно работать с любым элементом дерева: у всех есть имя, владелец, группа, права, время создания и изменения, ссылка на родителя и метод `get_size()`.

- `FileSystemEntry` (абстрактный) — общие атрибуты и поведение, метод `get_path()` строит абсолютный путь от корня.
- `File` — хранит содержимое в байтах и формат; размер вычисляется по длине содержимого.
- `Folder` — хранит дочерние элементы в словаре, размер считается рекурсивно как сумма вложенных.
- `Disk` — владеет корневой папкой, отслеживает занятое/свободное место, умеет разрешать пути (`resolve_path`).
- `User` — данные пользователя, группы, глобальные права.
- `Permissions` — числовая модель прав (owner/group/other) с проверками `can_read` / `can_write` / `can_execute`.
- `FileFormat` — перечисление форматов с привязкой к категории для сортировки.
- `FileSystem` — связывает всё вместе: хранит пользователей и диски, разрешает пути, сериализует состояние в JSON.

Операции вынесены в отдельные модули пакета `operations`, а разбор пользовательского ввода — в `cli`. Ядро ничего не знает о способе взаимодействия, а CLI не содержит бизнес-логики. Такое разделение упрощает сопровождение и покрытие тестами.

Проект написан по PEP8 с аннотацией типов; ошибочные ситуации (отсутствие файла, нехватка прав, попытка удалить непустую папку и т. п.) обрабатываются через механизм исключений.

## Модель прав доступа

Права заданы в восьмеричной системе по образцу Unix. Для каждой из трёх категорий (владелец, группа, остальные) действует комбинация трёх флагов:

| Флаг | Значение | Право     |
|------|----------|-----------|
| `r`  | 4        | Чтение    |
| `w`  | 2        | Запись    |
| `x`  | 1        | Выполнение / доступ в папку |

Например, режим `755` означает `rwxr-xr-x`: владелец — полный доступ, группа и остальные — чтение и вход в папку. Менять права может только владелец элемента или пользователь `admin`; менять владельца — только `admin`.

## Установка и запуск

Требуется Python 3.10+ (используется синтаксис `X | Y` в аннотациях типов). Внешних зависимостей нет — только стандартная библиотека.

```bash
git clone <адрес-репозитория>
cd <папка-проекта>
python main.py
```

При первом запуске создаётся начальная конфигурация: пользователь `admin`, диск `C:` и корневая папка. Состояние сохраняется в `data/state.json` при выходе.

## Команды CLI

| Команда  | Синтаксис                          | Описание |
|----------|------------------------------------|----------|
| `ls`     | `ls [путь]`                        | Список содержимого папки |
| `cd`     | `cd <путь>`                        | Перейти в папку |
| `pwd`    | `pwd`                              | Показать текущий путь |
| `tree`   | `tree [путь]`                      | Дерево каталога |
| `touch`  | `touch <имя>`                      | Создать пустой файл |
| `mkdir`  | `mkdir <имя>`                      | Создать папку |
| `write`  | `write <файл> <текст>`             | Записать текст в файл |
| `cat`    | `cat <файл>`                       | Вывести содержимое файла |
| `cp`     | `cp <источник> <назначение>`       | Копировать файл |
| `mv`     | `mv <источник> <назначение>`       | Переместить или переименовать файл |
| `rm`     | `rm [-r] <путь>`                   | Удалить файл или папку (`-r` — рекурсивно) |
| `chmod`  | `chmod <режим> <путь>`             | Изменить права (восьмеричные, напр. `755`) |
| `chown`  | `chown <пользователь> <путь>`      | Сменить владельца (только admin) |
| `lsperm` | `lsperm [путь]`                    | Показать владельца, группу и права |
| `archive`| `archive <имя_архива> <файл...>`   | Заархивировать файлы в ZIP |
| `extract`| `extract <архив> [папка]`          | Распаковать архив |
| `backup` | `backup [имя]`                     | Создать резервную копию диска |
| `restore`| `restore <имя_файла>`              | Восстановить диск из копии |
| `organize`| `organize <папка>`                | Разложить файлы по категориям |
| `help`   | `help`                             | Справка по командам |
| `exit`   | `exit`                             | Сохранить состояние и выйти |

Пути поддерживаются как абсолютные (от корня `/`), так и относительные, включая `.` (текущая) и `..` (родительская папка).

## Пример работы

```
/> mkdir documents
Папка 'documents' создана
/> cd documents
/documents> touch notes.txt
Файл 'notes.txt' создан
/documents> write notes.txt Привет, мир
Содержимое записано в 'notes.txt'
/documents> cat notes.txt
Привет, мир
/documents> lsperm notes.txt
Путь: /documents/notes.txt
Владелец: admin
Группа: users
Права: rwxr-xr-x
/documents> archive backup.zip notes.txt
Архив 'backup.zip' создан
```

## Сохранение состояния

Всё дерево файловой системы, пользователи, диски и текущее положение сериализуются в `data/state.json`. Файлы хранятся в шестнадцатеричном виде, что позволяет корректно сохранять любое двоичное содержимое (например, ZIP-архивы). При запуске состояние восстанавливается вместе с родительскими связями элементов дерева. Сохранение происходит при команде `exit` и при прерывании работы (Ctrl+C).
